A Windows x64 portable release from the **bluemoonandy/maccanvas** fork.

### HEVC display improvements

- Handle HEVC coded/display dimensions correctly, including 1920×1088 pictures cropped to a 1920×1080 display.
- Fill Slint pixel buffers directly during GPU readback, avoiding an intermediate RGBA allocation and full-frame copy.
- Keep the existing decoder selection, pacing limits, software fallback and Windows features.

In the supplied RTX 3060 Ti / 3840×2160 Release logs, comparable active windows improved from approximately **29.6 to 37.6 submitted frames/s**, with a sampled peak of **40.9 FPS**. Average frame preparation/submission time decreased from approximately **18.8ms to 12.1ms**. These observations are workload-specific; **stable 60 FPS has not been achieved or guaranteed**. Intel Arc Pro performance has not been measured in these logs.

### Portable installation

Download **MacCanvas-windows-x64-portable.zip**, extract it into a new folder, close older MacCanvas instances, and run `MacCanvas-windows-x64.exe`. Keep the included audio helper beside it; the viewer verifies the helper against its compiled size and SHA-256. The separate audio license notices are included.

The existing installer and in-app update source still point to the upstream project. For this fork, download upgrades from this repository's release page. This release does not change the update trust rules and does not publish the upstream installer as a fork installer.

### Optional diagnostics

Normal launches do not enable the extra performance counters. To collect per-second HEVC pipeline summaries from this Release executable, start it in PowerShell:

```powershell
$env:MACCANVAS_HEVC_DIAGNOSTICS = '1'
.\MacCanvas-windows-x64.exe
```

Diagnostic schema 2 separates pixel-buffer allocation, GPU readback, Slint image construction and image-setting costs. No frame content, passwords, keys or clipboard content is added to these summaries. See `docs/hevc-diagnostics.md` in the source for collection details and metric limitations.

### Build verification

Windows CI runs the existing automated tests, Clippy, installer checks, executable import verification and self-update replacement checks before publishing. Third-party Rust dependency caching reduces repeat compilation without removing these checks. Hardware-specific manual GPU tests still require a compatible physical Windows GPU.

`SHA256SUMS.txt` includes hashes for both executables and the portable ZIP. The ZIP contains executable checksums; its own checksum is listed in the separately downloadable file.
